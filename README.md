## 📖 Overview
This repository contains the Infrastructure-as-Code (IaC) configuration to deploy a lightweight **Security Operations Center (SOC)** for home network monitoring. 

It integrates **Suricata** (Intrusion Detection System) with the **ELK Stack** (Elasticsearch, Logstash, Kibana) to detect, log, and visualize network threats in real-time.

## 🏗️ Architecture
The entire stack is containerized using Docker for rapid deployment.

* **Suricata:** Inspects network traffic and generates alerts for suspicious activity (e.g., malware beacons, port scans).
* **Elasticsearch:** Stores the logs and alerts generated by Suricata.
* **Kibana:** Provides a web dashboard to visualize attack data and analyze trends.

## 🚀 Deployment
### Prerequisites
* Docker & Docker Compose installed on a Linux host (Ubuntu/Debian recommended).

### Usage
1.  Clone the repository:
    ```bash
    git clone [https://github.com/Anonymouse-dev-hub/Home-Lab-SOC.git](https://github.com/Anonymouse-dev-hub/Home-Lab-SOC.git)
    ```
2.  Start the cluster:
    ```bash
    docker-compose up -d
    ```
3.  Access the dashboard:
    * **Kibana:** `http://localhost:5601`
    * **Elasticsearch:** `http://localhost:9200`

## 📂 Configuration
The `docker-compose.yml` defines the service orchestration. Suricata operates in `host` network mode to ensure visibility into all network traffic interfaces.

## ⚠️ Disclaimer
This setup is intended for educational purposes and home lab environments. Running this on public networks requires additional security hardening.
